# heart-disease-prediction


# ❤️ Heart Disease Prediction Using Machine Learning

## 📌 About the Project
This project uses Machine Learning classification algorithms
to predict the heart disease class from patient health
measurements. It includes a Streamlit web interface.

## 🚀 Features
- Interactive patient input form
- Five Machine Learning models
- Heart disease class prediction
- Model probability display when supported
- Web interface accessible through a browser

## 🤖 Machine Learning Models
1. Logistic Regression
2. K-Nearest Neighbors (KNN)
3. Gaussian Naive Bayes
4. Decision Tree
5. Support Vector Machine (SVM)

## 🛠️ Technologies Used
- Python
- Pandas
- Scikit-learn
- Streamlit
- Pickle

## 📂 Project Structure
```text
heart-disease-prediction/
├── app.py
├── requirements.txt
├── logistic_regression.pkl
├── knn.pkl
├── naive_bayes.pkl
├── decision_tree.pkl
└── svm.pkl
```

## ▶️ Run Locally
Install the dependencies:

```bash
pip install -r requirements.txt
```

Start the application:

```bash
streamlit run app.py
```

## ⚠️ Disclaimer
This project is for educational purposes only.
It is not a medical diagnostic tool and must not be used
to make medical decisions.
